# Getting Started

This guide will help you get started with the Metronome Widget.

## Using the Web Application

The easiest way to use the Metronome Widget is through the live web application:

1. Visit [https://doneldoug.github.io/metronome-widget/](https://doneldoug.github.io/metronome-widget/)
2. The metronome is ready to use immediately - no installation required!
3. Click the play button to start the metronome
4. Adjust the tempo using the plus/minus buttons or settings

## Running Locally

If you want to run the metronome widget locally:

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- A local web server (optional, for best results)

### Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/DonElDoug/metronome-widget.git
   cd metronome-widget
   ```

2. Open `index.html` in your web browser:
   - You can double-click the file, or
   - Use a local web server for better performance

3. Using a local web server (recommended):
   ```bash
   # Using Python 3
   python -m http.server 8000

   # Or using Node.js http-server
   npx http-server
   ```

4. Open your browser to `http://localhost:8000`

## Browser Compatibility

The Metronome Widget works on all modern browsers:
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+
