# Features

The Metronome Widget includes a comprehensive set of features for musicians of all levels.

## Core Features

### Tempo Control
- **Adjustable BPM**: Set your desired beats per minute
- **Plus/Minus Buttons**: Increment or decrement tempo easily
- **Wide Range**: Support for a full range of musical tempos from very slow to very fast

### Playback Controls
- **Play/Pause**: Start and stop the metronome with a single click
- **Visual Feedback**: See when the metronome is active

## Audio Options

### Sound Selection
- **Classic Click**: Traditional metronome click sound (`click.wav`)
- **Flute Sound**: Alternative Japanese flute sound option (`flute_japan.mp3`)
- **High Quality Audio**: Clear, crisp audio samples

### Audio Features
- Consistent, reliable timing
- Low latency playback
- Volume control (if supported in your browser)

### Settings

## User Interface

### Clean, Modern Design
- Minimalist interface focused on functionality
- Large, easy-to-see controls
- Custom typography using iAWriter Mono font
- Intuitive icon-based controls

### Visual Icons
The application uses clear, recognizable icons:
- ▶️ Play: Start the metronome
- ⏸️ Pause: Stop the metronome
- ➕ Plus: Increase tempo
- ➖ Minus: Decrease tempo
- 🔄 Refresh: Reset settings
- ⚙️ Settings: Access configuration
- 🎲 Random: Toggle random mode
- ⚡ Speed: Toggle speed variations

## Technical Features

- **Lightweight**: Fast loading and minimal resource usage
- **Responsive**: Works on desktop and mobile devices
- **Offline Capable**: Can run without an internet connection once loaded
- **No Dependencies**: Pure web technologies, no external libraries needed
