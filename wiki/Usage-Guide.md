# Usage Guide

Learn how to get the most out of your Metronome Widget.

## Basic Usage

### Starting the Metronome

1. **Open the Application**: Navigate to the metronome widget in your web browser
2. **Set Your Tempo**: Use the plus (+) and minus (-) buttons to adjust the BPM
3. **Click Play**: Press the play button (▶️) to start the metronome
4. **Practice**: Play along with the steady beat
5. **Click Pause**: Press the pause button (⏸️) when finished

### Adjusting Tempo

The tempo controls allow you to set the perfect speed for your practice:

- **Increase Tempo**: Click the plus (+) button
- **Decrease Tempo**: Click the minus (-) button
- **Fine Control**: Make small adjustments to find your ideal tempo
- **Visual Feedback**: The current BPM is displayed on screen

## Advanced Features

### Using Different Sounds

The metronome offers multiple sound options:

1. **Open Settings**: Click the settings icon (⚙️)
2. **Select Sound**: Choose between:
   - Classic click sound (default)
   - Japanese flute sound (alternative)
3. **Apply**: The new sound will be used immediately

### Speed Variations

Speed mode allows you to practice with tempo variations:

1. **Enable Speed Mode**: Click the speed icon
2. **Icon Changes**: The icon will show "on" state (⚡ in color)
3. **Practice**: The metronome will vary the tempo slightly
4. **Disable**: Click again to return to steady tempo

### Random Mode

Random mode introduces unpredictability for advanced practice:

1. **Enable Random**: Click the random icon (🎲)
2. **Varied Patterns**: The metronome will create varied rhythmic patterns
3. **Challenge Yourself**: Great for improving timing independence
4. **Disable**: Click again to return to regular beats

### Resetting to Defaults

To return to the default settings:

1. **Click Refresh**: Press the refresh icon (🔄)
2. **Confirm**: Settings will reset to defaults
3. **Ready to Go**: Start fresh with standard settings

## Tips for Practice

### Building Speed Gradually

1. Start at a comfortable slow tempo
2. Practice the passage until it's clean
3. Increase by 5-10 BPM
4. Repeat until you reach target tempo

### Working with Difficult Passages

1. Set the metronome to a slow tempo
2. Play the difficult section repeatedly
3. Focus on accuracy over speed
4. Gradually increase tempo as you improve

### Time Signature Practice

While the current version focuses on steady beats:
- Count beats yourself for different time signatures
- Use the metronome for the underlying pulse
- Practice subdivisions mentally

### Using Random Mode

Random mode is excellent for:
- Developing internal timing
- Breaking dependence on the metronome
- Improving rhythmic confidence
- Simulating performance conditions

## Keyboard Shortcuts

*(If implemented)*
- `Space`: Play/Pause
- `+` or `→`: Increase tempo
- `-` or `←`: Decrease tempo
- `R`: Reset to default

## Troubleshooting

### No Sound?

1. **Check Volume**: Ensure your device volume is up
2. **Browser Permissions**: Allow audio in browser settings
3. **Try Different Sound**: Switch between click and flute sounds
4. **Reload Page**: Refresh the browser window

### Timing Issues?

1. **Close Other Tabs**: Free up browser resources
2. **Use Modern Browser**: Ensure you're using a current browser version
3. **Check System Load**: Close unnecessary applications
4. **Try Different Device**: Test on another computer or phone

### Page Not Loading?

1. **Check Connection**: Ensure internet connection (for initial load)
2. **Clear Cache**: Clear browser cache and reload
3. **Try Different Browser**: Test in Chrome, Firefox, or Safari

## Mobile Usage

The metronome works great on mobile devices:

1. **Add to Home Screen**: Save as an app icon
2. **Portrait Mode**: Best experience in portrait orientation
3. **Keep Screen On**: Adjust your device settings to prevent sleep
4. **Use Headphones**: For better audio clarity

## Best Practices

### Regular Practice
- Use the metronome for at least part of every practice session
- Don't rely on it 100% - also practice without it
- Record yourself to check timing accuracy

### Gradual Tempo Increases
- Never sacrifice accuracy for speed
- Make small tempo increases (5-10 BPM)
- Consolidate improvements before moving faster

### Variety in Practice
- Practice with different sounds
- Use random mode occasionally
- Vary your practice routine
